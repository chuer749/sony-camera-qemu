# 历史验证摘要

日期：2026-10-31。以下验证发生在本机归档前；它们验证的是离线工具装配或独立测试程序，不是完整 Sony 相机模拟。

## 离线工具

- 18 项离线单元测试通过，覆盖输入指纹匹配、未知版本拒绝、输出路径保护及失败时不发布半成品等情况。
- 使用合成 FAT 镜像和占位分区走通生成流程，并检查生成结果和篡改拒绝路径。测试没有使用 Sony 固件。
- 对生成布局、输入不变性、候选 A7R IIIA 配置拒绝生成及错误输入处理做了离线检查。

## QEMU 环境

- 固定版本的 ARM QEMU 容器构建成功，运行环境检查通过。
- 独立 ARM 程序在 CXD90045 候选模型上输出 UART 标记。此实验没有使用 Sony 固件，不验证 Linux 内核、相机驱动、GPU、菜单或拍摄链。

## 不支持的结论

- 没有验证 A7M3 或 A7R IIIA 的真实固件端到端启动。
- 没有验证 A7R IIIA 的分区构建配方、USB 采集、认证或设备恢复。
- 没有验证原生菜单、显示、GPU、按键、触控或成像。

固件、生成磁盘、完整日志和本机 Docker 镜像标识未包含在公开仓库中。
